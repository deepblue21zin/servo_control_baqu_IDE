# 2026-05-04 Change Log

## 00:12 KST

- 수정 파일
  - `Core/Inc/project_params.h`
  - `Core/Src/encoder_reader.c`
  - `Core/Src/rs422_encoder_uart.c`
  - `Core/Src/adc_potentiometer.c`

- 무엇을 어떻게 바꿨는지
  - 12.5:1 감속기 기준으로 motor-axis soft limit을 `+/-4320.0 deg`에서 `+/-562.5 deg`로 조정했다.
  - 도달 판정 `STABLE_ERROR_THRESHOLD`를 `0.5 motor deg`에서 `2.5 motor deg`로 바꿔 조향축 기준 약 `+/-0.2 deg`가 되도록 했다.
  - 초기 벤치 안정화 파라미터로 `DEFAULT_INTEGRAL_LIMIT`을 `500.0f`, `DEFAULT_OUTPUT_LIMIT`을 `3000.0f`로 조정했다.
  - `ENCODER_COUNT_POLARITY`와 `ADC_POT_STEERING_POLARITY`가 `+1` 또는 `-1`만 허용되도록 compile-time guard를 추가했다.
  - TIM2 encoder delta 누적 경로에 `ENCODER_COUNT_POLARITY`를 실제 적용했다.
  - RS422 encoder relative count에도 `ENCODER_COUNT_POLARITY`를 적용해 motor/steering degree 로그 방향을 시스템 기준과 맞췄다.
  - ADC potentiometer raw-to-angle 변환에도 `ADC_POT_STEERING_POLARITY`를 적용했다.

- 수정 이유
  - 조향 모터가 12.5:1 감속기를 거친 상태이므로 외부 조향각 기준과 내부 모터각 기준을 명확히 분리해야 한다.
  - 기존에는 polarity 매크로가 선언만 되어 있고 실제 count 변환에 반영되지 않아 방향 반대 장착 시 오차가 커질 수 있었다.
  - 기존 도달 판정은 motor 기준 `0.5 deg`라 조향축 기준 약 `0.04 deg`로 너무 빡빡해 실제 조향 시스템의 `+/-0.2 deg` 판정 요구와 맞지 않았다.

- 영향 범위
  - TIM2 encoder, RS422 encoder, ADC potentiometer의 부호 변환 기준이 `project_params.h`의 polarity 설정을 따른다.
  - position control의 목표/현재/error 내부 단위는 계속 motor deg이며, keyboard/UDP/log의 조향각 변환 구조는 유지된다.
  - `DEFAULT_OUTPUT_LIMIT=3000.0f`는 초기 안정화용으로 약 `0.72 steering deg/s` 수준이라, 속도 시험 시 목표 조향 속도에 맞춰 다시 높여야 한다.
