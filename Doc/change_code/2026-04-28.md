- 무엇을 어떻게 바꿨는지
  - 시스템 SW / 제어 / 임베디드 취업 준비 관점에서 현재 프로젝트의 핵심 C 코드 소유권을 회복하기 위한 실행 문서를 새로 추가했다.
  - `encoder_reader.c`, `pulse_control.c`, `position_control_safety.c`, `position_control.c`, `app_runtime.c`를 우선 소유해야 할 P0 코드로 지정했다.
  - TIM1 PWM과 TIM2 encoder를 HAL 아래 레지스터 수준까지 확인하기 위한 필수 부록 작업을 정리했다.
  - AI 사용 규칙, 매일 60~90분 루틴, 2주 집중 일정, 면접용 핵심 문장, 완료 체크리스트를 문서화했다.
  - 루트 `README.md`와 `Doc/README.md` 문서 인덱스에 새 문서를 연결하고 최신 기준일을 2026-04-28로 갱신했다.
- 수정 이유
  - 사용자가 AI가 코드를 만들고 본인은 따라가는 느낌을 가장 큰 문제로 인식하고 있어, 취업 준비 기간 안에 직접 코드 해석/수정/검증 능력을 끌어올릴 수 있는 프로젝트 내부 실행 계획이 필요했다.
  - 레지스터 raw 레벨 학습을 별도 대형 프로젝트가 아니라 현재 TIM1/TIM2 경로의 HAL-to-register 확인으로 연결하기 위해서다.
- 영향 범위
  - 코드 동작에는 영향이 없다.
  - 문서 탐색 흐름과 취업 준비 체크리스트가 추가되었다.
  - 포털 점수, 시뮬레이션 기준값, runtime 파라미터는 변경하지 않았다.
