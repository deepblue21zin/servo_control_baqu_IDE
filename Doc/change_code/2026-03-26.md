  - `PositionControl_ResetStats()`, `PositionControl_GetStats()`를 실제 누적 통계와 연결하고, 루프마다 `max_error`, `avg_error`, `update_count`, `overshoot_count`, `max_settle_time_ms`가 갱신되도록 구현함
  - `PositionControl_RegisterErrorCallback()`와 `PositionControl_RegisterStableCallback()`을 실제 callback 등록 API로 구현하고, error transition 및 stable false->true 전이에서 hook이 호출되도록 연결함
  - `PositionControl_SetDebugLevel()`을 자동 로그 verbosity 제어와 연결하고, command lifecycle 및 controller 상태 로그를 debug level 기준으로 출력하도록 정리함

  - velocity safety를 구분하기 위해 error/result/debug fault 비트에 velocity 항목을 추가함
- 수정 이유:
  - position controller public API에 선언만 되어 있고 실제 동작하지 않던 safety/stats/callback/debug 기능을 제어 루프와 연결해, 상위 supervisor 및 bench 진단에서 바로 쓸 수 있는 수준으로 올릴 필요가 있었음
  - 안정 판정 기준이 헤더 상수와 실제 구현 사이에서 분리되어 있어, callback과 통계를 붙이면 기준이 이중화되는 문제가 있었음

  - 상위 모듈이 사용할 수 있는 callback hook 및 stats API
