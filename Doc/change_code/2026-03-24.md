- 영향 범위:
  - `PD12/PD13`에 파형이 보이는데도 `ENC`가 고정되는 상황에서 실제 `CNT` 변화와 `TIM4` encoder 인터페이스 유지 여부를 UART 로그만으로 더 빠르게 판별할 수 있게 됨
  - 이후 bench 진단에서 하드웨어 입력 체인 문제와 타이머 설정 문제를 분리하는 시간이 줄어듦
