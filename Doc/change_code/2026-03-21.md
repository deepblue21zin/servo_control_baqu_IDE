- 이유:
  - 동적 시뮬레이션이 `target angle` 슬라이더를 움직일 때 목표와 현재가 동시에 따라가 보여서, fixed pulse frequency에 따라 실제로 이동하는 느낌을 전달하지 못했음
- 수정 내용:
  - `target marker`와 `current needle`을 분리해 목표는 고정 표시, 현재는 0 deg에서 목표값까지 시간 기반으로 이동하도록 변경함
  - `replay` 버튼, 진행률 바, 실행 상태 텍스트를 추가해 설정 후 다시 재생하고 도달 시간과 pulse 진행량을 한눈에 볼 수 있게 함
  - `frequency`와 `target angle`을 바꾸면 12:1 기어비, `4000 pulse / steering_deg` 기준으로 예상 이동 시간과 ideal trace가 같이 갱신되도록 연결함
- 영향:
  - 포털의 시뮬레이션이 단순 설명 UI에서 `target / current / move duration`을 구분해 보여주는 형태로 개선됨
  - 처음 보는 사람도 fixed-speed move 개념과 target arrival 시간을 더 직관적으로 이해할 수 있게 됨
