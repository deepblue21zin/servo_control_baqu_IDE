# 2026-05-06 Change Log

## 13:26 KST

- 수정 파일
  - `.gitignore`
  - `.metadata/*` Git 추적 해제
  - `.vscode/settings.json` Git 추적 해제
  - `FETCH_HEAD` Git 추적 해제

- 무엇을 어떻게 바꿨는지
  - `.gitignore`에 `.metadata/`, `.vscode/`, 로컬 로그/임시 파일 패턴을 추가했다.
  - 이미 Git에 올라가 있던 `.metadata/`, `.vscode/settings.json`, `FETCH_HEAD`는 `git rm --cached`로 인덱스에서만 제거했다.
  - 로컬 파일은 삭제하지 않고 그대로 남겼다.

- 수정 이유
  - `.metadata/`는 STM32CubeIDE/Eclipse workspace 내부 상태와 lock/log 파일이라 팀 소스 저장소에 포함되면 재현성과 리뷰 품질을 떨어뜨린다.
  - `FETCH_HEAD`는 Git 작업 중 생기는 로컬 임시성 파일이라 저장소에 포함할 필요가 없다.
  - `.vscode/settings.json`은 현재 로그 파일 association 중심의 로컬 편의 설정이라 펌웨어 빌드 재현에 필수 파일이 아니다.

- 영향 범위
  - 다음 커밋부터 해당 파일들은 저장소 추적 대상에서 빠지고, 이후 로컬에서 다시 생성/변경되어도 Git status에 나타나지 않는다.
  - `Debug/` 빌드 산출물은 기존 `.gitignore` 정책 그대로 무시된다.
  - 실제 펌웨어 소스, CubeMX `.ioc`, linker script, HAL/LwIP vendor 파일에는 영향이 없다.
