# Change Code Log Rule

이 폴더는 코드 수정 이력을 날짜별로 누적 기록하는 용도다.

## 파일 규칙

- 파일명은 반드시 `YYYY-MM-DD.md`
- 하루에 여러 번 수정하면 같은 날짜 파일에 계속 추가
- 새로운 수정이 이전 수정 내용을 대체하면 기존 항목은 지우지 않고 `~~취소선~~` 처리
- 취소선 아래에 "왜 수정되었는지"와 "최종 반영 내용"을 이어서 적기

## 권장 형식

```md
# 2026-03-15

## 변경 요약
- 03-15-01: 무엇을 수정했는지

## 03-15-01 10:30
- 파일: `Core/Src/example.c`
- 이유: 어떤 문제가 있었는지
- 수정 내용:
  - 무엇을 어떻게 바꿨는지
- 영향:
  - 어디에 영향을 주는지
```

## 같은 날짜에 재수정하는 예시

```md
## 변경 요약
- ~~03-15-01: `example.c`에서 A 방식으로 수정~~
  - 대체 이유: 이후 테스트에서 B 방식이 더 맞는 것으로 확인됨
- 03-15-02: `example.c`에서 B 방식으로 재수정
```

핵심 원칙은 "지우지 말고 남기기"다.
