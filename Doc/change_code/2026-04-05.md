  - `R` 키로 우회전 시나리오를 시작하고 `C` 키 또는 수동 target 입력으로 즉시 취소되도록 했다.
  - 시나리오의 단계 각도, 최대 각도, 단계 유지 시간, 피크 유지 시간을 `project_params.h`에서 한곳에서 바꿀 수 있게 설정값을 추가했다.
  - keyboard 도움말에도 새 시나리오 키와 현재 시나리오 파라미터를 같이 표시하도록 갱신했다.
- 수정 이유
  - 사용자가 keyboard bench에서 실제 조향 명령 흐름과 비슷한 step/ramp 프로파일을 반복적으로 시험하고 싶어 했고, 수동으로 `10`, `20`, `30`을 계속 치는 대신 재현 가능한 시나리오가 있으면 훨씬 편하기 때문이다.
- 영향 범위
  - keyboard 시험 중 `R` 한 번으로 같은 우회전 프로파일을 반복 재생할 수 있다.
  - 기존 수동 입력(`A/D/S`, 숫자 입력, enable/disable, estop`)은 그대로 유지되며, 수동 조작이 들어오면 자동 시나리오는 즉시 멈춘다.
