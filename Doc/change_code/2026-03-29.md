  - 제어 루프 자체는 그대로 두고, 관측성만 개선해서 원인 분리를 더 쉽게 하려는 목적이다.

- 영향 범위

  - 엔코더 초기화와 TIM2 엔코더 시작은 그대로 유지된다.
