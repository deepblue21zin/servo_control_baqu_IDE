Live Debug Viewer

PuTTY Log Live Viewer

`putty.log`를 브라우저에서 읽어 `LATENCY`, `KB`, `CMD`, `CSV`, `ENCDBG`, `BOOT/SYSTEM` 타입으로 자동 분류한다. Python bridge를 쓰면 새 로그 라인이 들어오는 즉시 반영되고, fallback으로 polling, 파일 권한 연결, snapshot 업로드도 지원한다.

연결 방식

아직 로그 소스가 연결되지 않았다. `Bridge live 연결`, `파일 polling 연결`, `로컬 파일 권한 연결`, `snapshot 업로드` 중 하나를 선택하면 된다.

가장 추천되는 방식은 `putty_log/start_putty_live_viewer.ps1`로 Python bridge, 브라우저, PuTTY logging을 한 번에 띄우는 것이다. 브리지 모드에서는 `putty.log`에 새 줄이 추가될 때 브라우저가 거의 즉시 반영한다. 파일로 직접 열었을 때는 upload 또는 파일 권한 연결 모드를 사용하면 된다.
