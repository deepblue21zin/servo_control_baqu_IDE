# 취업 연계 프로젝트 로드맵

작성 기준일: 2026-03-12
개발 완료 목표: 2026-05-31 기능 완료, 2026-06-15 검증/포트폴리오 정리 완료
대상 프로젝트: `servo_control_baqu`

## 1. 이 프로젝트를 어떻게 포지셔닝할 것인가

이 프로젝트는 "자율주행 전체 시스템"으로 넓히는 것보다, 아래 한 줄로 정의하는 것이 취업에 더 유리하다.

> STM32 기반 조향 액추에이터 서브컨트롤러를 설계하고, 1ms 폐루프 제어, homing, fail-safe, Ethernet 연동, latency 근거까지 검증한 프로젝트

이 포지셔닝이 좋은 이유는 다음과 같다.

1. 조향제어, ADAS, 임베디드 SW 직무와 직접 연결된다.
2. 실시간 제어, 센서 피드백, 안전 경로, 상위기 통신을 모두 설명할 수 있다.
3. "동작했다"가 아니라 "요구사항, 검증, 장애 대응"까지 설명할 수 있다.
4. 혼자서도 끝까지 완성 가능한 범위다.

## 2. 취업 관점에서 반드시 가져가야 할 핵심 메시지

이 프로젝트에서 채용담당자나 현업 엔지니어가 좋게 보는 포인트는 아래 순서다.

1. 제어기 본체를 안정적으로 만들었는가
2. 안전정지와 복귀 절차를 설계했는가
3. 센서값과 제어값의 단위를 명확히 정의했는가
4. 통신 장애, 센서 이상, 추종 실패에 대한 fail-safe가 있는가
5. 성능과 테스트 결과를 숫자로 제시할 수 있는가

반대로 지금 시점에서 욕심내지 않는 것이 좋은 항목은 아래다.

1. 인지/판단 알고리즘 자체 구현
2. RTOS 이관
3. CAN 추가
4. GUI 제작
5. 너무 많은 주변 기능 확장

우선순위는 "조향 액추에이터 제어기 완성도"가 가장 높다.

## 3. 지금 바로 잡아야 하는 핵심 기술 이슈

현재 코드와 문서를 기준으로, 가장 먼저 정리해야 하는 이슈는 아래 4개다.

### 3.1 단위 체계 혼선 정리

현재 문서에는 아래 값들이 혼재되어 있다.

- 조향축 기준 각도: 예) `-45 ~ +45 deg`
- 모터축 기준 각도: 예) `-4320 ~ +4320 deg`
- 엔코더 count 기준 값

이 상태로는 면접에서 설계를 설명하기 어렵고, 팀 작업도 쉽게 꼬인다. 따라서 2026-03-31 이전에 아래 원칙으로 고정하는 것을 권장한다.

- 외부 인터페이스: `steering_deg`
- 내부 제어/안전 계산: `motor_deg`
- 센서 원본: `encoder_count`, `adc_raw`
- 변환 상수: `gear_ratio`, `deg_per_count`, `pulse_per_deg`

### 3.2 Homing을 실제 startup 시퀀스에 넣기

현재 `homing`과 `adc_potentiometer`는 코드상 존재하지만 실제 부팅 경로에서는 주석 처리되어 있다. 취업용 프로젝트로 보이려면 "기능 존재"가 아니라 "부팅 시퀀스에서 동작"해야 한다.

### 3.3 센서 신뢰성 확보

현재 `encoder_reader`는 16비트 counter를 직접 사용하고 있어 장시간 운전 시 unwrap 누적이 없다. `adc_potentiometer`도 보정, 유효성 판정, cross-check 기능이 부족하다. 이 부분은 포트폴리오 관점에서 강하게 보강해야 한다.

### 3.4 안전 경로를 문서와 코드 모두로 증명

`relay_control`, `position_control`, `ethernet_communication`이 각자 안전 동작 일부를 담당하고 있으므로, 전원 인가, 통신 timeout, EMG, 복귀 절차를 하나의 state machine으로 설명 가능해야 한다.

## 8. 최종적으로 이 프로젝트에서 말할 수 있어야 하는 것

면접에서는 아래 정도로 설명 가능해야 한다.

1. 왜 이 프로젝트를 자율주행 조향 액추에이터 서브컨트롤러로 정의했는지
2. 상위 제어기와 하위 제어기 역할을 어떻게 나눴는지
3. 센서, 제어, 출력, 안전 경로가 어떻게 연결되는지
4. 어떤 요구사항을 세우고 어떻게 검증했는지
5. 아직 남은 한계가 무엇이고, 다음 단계가 무엇인지

이 프로젝트의 핵심은 "모터가 돈다"가 아니라, "현업 방식으로 조향 제어기를 설계하고 검증했다"는 점이다.
